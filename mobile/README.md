# FloodSense Android application

This directory contains the Flutter Android project. Its Android application ID
is `ph.edu.cvsu.bacoor.floodsense`.

From this directory, use:

```powershell
flutter pub get
flutter analyze
flutter test
flutter run
```

Use an Android emulator or a USB-connected Android phone for `flutter run`.
Keep demonstration screens and fixtures visibly labelled until Bacoor-specific
data and expert rules are approved.
