Fixed methodology

Scenario assessment method

FloodSense uses deterministic rule-based inference: a user triggers an assessment using a chosen scenario and stored inputs subject to source and operating-mode policies. The parameter-governance workflow is still pending.

No machine-learning model, real-time rainfall monitoring, or background forecasting is used. This page does not change the algorithm.
