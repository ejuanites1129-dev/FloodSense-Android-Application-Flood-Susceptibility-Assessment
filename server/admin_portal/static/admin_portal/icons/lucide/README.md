# Lucide icons

These static SVGs were supplied by the project owner from Lucide downloads on
6 October 2026. The source folder happened to be named `Downloads/Flaticon`;
these are Lucide assets, not Flaticon assets. Original SVG bytes are unchanged.

`manifest.json` records their use, official pages, pinned upstream sources,
geometry verification and SHA-256 checksums. Each supplied shape and standard
SVG drawing attribute was compared with the official Lucide repository.
Website downloads differ from repository files in formatting and preview classes.

Keep the accompanying `LICENSE` with any copy or distribution of these assets,
including collected deployment static files. It includes the ISC license and
the MIT notices for Feather-derived icons (including monitor and clock).
Lucide does not require a visible interface attribution link:
https://lucide.dev/license

The reusable `portal_icon` component renders them as decorative 20px images and
CSS masks that inherit interface colors. Existing accessible link/button names
provide their meaning; these images do not take focus or receive pointer events.
No external runtime, script, animation or application dependency is needed.

The supplied `map.svg` is unused; Map data uses `map-pinned.svg`. It was not
copied into the application. FloodSense branding, avatars and unrelated controls
keep their existing artwork. Lordicon assets and their footer credit were removed
when the active icon mapping was replaced.
